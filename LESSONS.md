**Copyright (c) 2026 Martial Systems LLC.** MIT.

Grok does **not** remember a fix from one repo in the next chat. This file does.

At the start of implement or UI work: apply every row whose **When** matches, unless **Skip when** matches. If you discover a general miss, add a row here and on the drop-ins. Do not leave it only in the project that hit it.

| Date | Lesson | When | Skip when |
|------|--------|------|-----------|
| 2026-08-24 | Cloudflare Pages: a directory `foo/` without `foo/index.html` wins over `foo.html`, so `/foo` 404s or SPA-falls through to the homepage. Nested `_redirects` `/*.html /:splat` also rewrites `/dir/index.html` to `/dir/index`. Ship `foo/index.html` when a sibling folder exists, and use `/:file.html /:file` for top-level pretty URLs only. Do not treat “the button went to home” as a CSS bug until those two are checked. | Public Pages/static sites with pretty URLs, mixed `foo.html` and `foo/` trees | Single-file sites with no subdirectories; hosts that do not prefer directories |
| 2026-08-24 | A public app folder is not live if only `index.html` is in git. Relative `app.js` / `app.css` / engine files 404 and the page is a dead shell. Commit every file the HTML `src`/`href` names, and sanity-check those relative assets on disk before deploy. | Folder apps (`/concepts/<name>/`) or any HTML with relative script/style URLs | Single self-contained HTML with no local assets |
| 2026-08-23 | `chrome.permissions.request` needs a user gesture. The toolbar popup (or other extension page) must call it on the click/change that enables a site. Relaying to the service worker and requesting there often fails with no prompt. | MV3 optional host or optional permission grant | Permission is already granted, or not using `optional_host_permissions` |
| 2026-08-22 | Chrome's extension popup and options shell already show the extension icon and name. Do not repeat that logo+title in `popup.html` or the user sees a double header. Keep a document `<title>`. | MV3 `action` popup or `options_ui` page | Standalone HTML that Chrome does not wrap |
| 2026-08-22 | An optional control on a measured overlay must be out of flow (`position: absolute`) if `getBoundingClientRect` of the host feeds placement math. Putting it in normal flow changes the box size and then the placement. Keep estimated fallback sizes unchanged. | Overlay or prompt UI whose measured size is used to place it | The control is supposed to grow the host |
| 2026-08-21 | A Grok marketplace plugin that needs a helper must ship that helper in the pinned git tree. A separate Release zip reads as download-and-run to reviewers even when xAI docs allow helper binaries delivered separately. | Submitting or updating a Grok marketplace plugin that runs local code | Helper is an OS tool already on PATH (`git`, `gh`, `python3`) |
| 2026-08-21 | Fetching dated discussion threads (HN Who is hiring, monthly mailing lists) by relevance returns decade-old hits. Sort by date and drop threads older than the current cycle. | Scraping monthly or dated threads | APIs that only return the current cycle |
| 2026-08-21 | A blank location field must not skip a location filter when title or snippet still names a city. Empty location plus Oslo in the comment is not "location unknown, keep it." | Search or scrape with a location include list | No location filter, or records truly have no location text |
| 2026-08-21 | MV3 `script-src 'self'` blocks inline event handlers (`onerror=`, `onclick=`). Chrome logs "Executing inline event handler violates CSP" even when the action is blocked. Do not emit `on*` attributes in extension HTML; bind with `addEventListener`. | MV3 extension UI | Non-extension pages that allow unsafe-inline |
| 2026-08-21 | MV3 extension pages: `<img src>` that 307s across hosts (Cover Art Archive → archive.org → `dn*.archive.org`) often fails, and a generic `/front-250` shortcut 503s while the stored image-id URL 200s. Use the stored URL first, a fallback src list, `host_permissions` for the whole redirect chain, `img-src https: data:` in extension CSP, and a service-worker fetch → data URL if `<img>` still errors. Do not hide an image on `error` if it already decoded (`naturalWidth > 8`). Cache a small thumb locally; full-size is a link, not a second stored file. | MV3 extension UI embedding third-party images via redirecting CDNs | Same-origin, `data:`, or `chrome-extension://` images only |
| 2026-08-20 | Heavy region dividers on a CSS grid belong on the region wrapper, not on each child. Child min-content (pencil notes, chips, badges) will jog a per-cell thick border so the main line looks broken. Keep notes or chips out of flow (`absolute` / `min-w-0` / `overflow-hidden`). | CSS grid with thick region lines and variable child content | No region lines, or children cannot change min-content |
| 2026-08-19 | JS-injected topbar chrome (theme / hamburger) and a first-visit `overflow: hidden` disclaimer are CLS sources. Reserve the chrome slot in first-paint HTML/CSS (`scrollbar-gutter: stable`). Do not `display:none` a panel that fetch later shows: that shifts everything below. | Public HTML with injected chrome or a gate modal | No public HTML / no layout |
| 2026-08-18 | Phone-width (390x844) and desktop (~1280) for UI, layout, nav, or in-page jumps. Named command, not a thought. Skip/hash must land the **visual** target (the chart), not a tall section header. Martialsys boards: `python3 viewer/scripts/viewport_sanity.py`. | Any HTML/CSS/nav/anchor change | No UI (pure backend, data, or docs-only with no layout) |
| 2026-08-21 | `color-scheme: light dark` with hardcoded dark ink (`#111`, `--fg`) on `Canvas` or a transparent body is unreadable in OS dark mode. Put copy on an explicit panel whose background and ink are set, or write a real `prefers-color-scheme: dark` pair. | HTML/CSS that opts into `color-scheme` or uses `Canvas`/`CanvasText` | Forced single theme with explicit fg and bg |
| 2026-08-16 | Fetch before edit. Dirty+ahead: stash, commit, or report both. Finish-later if local is edited and origin is not ahead. Push or say why. | Any git working tree | Not a git repo |
| 2026-08-16 | Do not overwrite a newer deploy artifact with an older one. Missing source keeps dest. | Site, Pages, board JSON, wrangler | No public/deploy copy |
| 2026-08-19 | An eval table that drops unlabeled rows looks frozen even when newer forecasts exist. Keep pending origin dates (actual empty) so last pred date is visible. | Public/lab error tables from forecast vs actual | Table is labeled-only and the copy says so |
| 2026-08-19 | `vbd_gate` is automatic: Grok Stop hook when the agent finishes a turn; git pre-push if the chat never claimed done. User does not run it by hand. | Any finish / push / deploy | Not a git repo and no tracked UI/docs change |
| 2026-08-19 | Hetzner is the martialsys Pages publisher. Host `deploy_viewer.sh` must find `vbd_gate.py` (clone `agent_laws_verify_before_done` at `$HOME` or `/root`, or set `VBD_GATE`). Missing pack is a hard fail, not warn-and-continue. Pre-push belongs on every product git, not only the research viewer. | Host or CI Pages publish; new product clone | Local preview that already has the pack |
| 2026-08-19 | `vbd_gate` appends one JSON line per invocation to `~/.grok/logs/vbd_gate.jsonl` (`VBD_GATE_LOG` override). Tail that file for step evidence. It is not GraphForge audit and not an interaction-map transcript. | After Stop, pre-push, deploy, or `vbd_gate check` | None |
| 2026-08-19 | After a passing VBD-pack push on this PC, publish the runner into private GraphForge (`vbd_gate.py publish-gf`). Enterprise gets new gate versions by GF clone/pull. Public MIT prose can stay. `VBD_SKIP_GF_PUBLISH=1` skips. | Push of `agent_laws_verify_before_done` | No GraphForge checkout; or skip env set |
| 2026-08-19 | Skip-landing evaluates every `.skip-juicy` hash href, not only the first. A first skip to the chart wrap must not hide a later skip onto the panel. | HTML with skip/hash jumps | No skip controls |
| 2026-08-19 | When adding a field to derived summaries, rebuild from the source artifacts and **lock** the fields that must not change (MAE/RMSE/n here) before any write. Fail the whole batch on drift. Do not retrain to attach a new metric. | Derived JSON/CSV rebuilt from prediction or eval logs | Brand-new artifact with no prior numbers |
| 2026-08-19 | A pipeline-generated markdown file is not a durable addendum store. Re-insert later records from a machine JSON, or keep them in a file the generator does not overwrite. Hand-editing `FREEZE_DECISION.md` (or similar) is lost on the next default run. | Pipeline writes a human report that later research appends to | Hand-authored docs only |
| 2026-08-19 | Before a new freeze recipe overwrites the locked eval JSON, snapshot the previous summary under a named baseline path. The lift must remain auditable after the default walk-forward is the new recipe. | Replacing a locked model recipe or freeze file | First freeze with no prior locked numbers |
| 2026-08-20 | A 10-bin PSI on ~21 daily rows (one calendar month) is degenerate and will CRITICAL on ordinary regime noise. Use a longer recent vs reference window (63 vs 252 here). Do not hard-block promote on raw non-stationary **levels** (range, RV) when PSI is a corruption gate; score those as report-only and block on scores / stationary transforms. | PSI as a promotion or freeze gate | PSI is only a diagnostic table with no block |
| 2026-08-20 | A paper/hold-out scorer that shares a production job's close must be a **separate workflow**, never `&&` inside the live pipeline. Fail isolation: the live job must succeed even if the sibling scorer dies. The paper job must not set live flags or write the freeze file. | Adding a second model on the same daily close as a live pipeline | The second path is already a separate repo/job |
| 2026-08-20 | Email/Slack alerts on a live pipeline must not change the job conclusion. Missing SMTP secret or a send error is a warning or fallback, never a red forecast. Success with no drift stays silent. | Adding mail/webhook alerts to a live CI job | The job's only purpose is to send the alert |
| 2026-08-20 | Fail-closed raw-bar checks belong **before** a live predict append, not only in a post-hoc validate step that can be skipped. Calendar vs the exchange, zero volume, and adjustment jumps are the usual silent-corrupt paths. | Live forecast or bar-data pipeline that appends a ledger row | Research notebooks that do not write a live log |
| 2026-08-19 | `get_command_or_subagent_output` with a positive timeout and multiple ids is wait-all. Duration is max(children), not tool overhead (successful joins return in ~1s). Use `timeout_ms: 0` snapshots or `wait_any`. Pipeline the next phase when the first child finishes. | Parallel Grok subagents | One child, or no subagents |
| 2026-08-19 | A new versioned manifest added on an old base stays stale after rebase onto a bumped tree. Set the new file's version to current `package.json` (or equivalent) and register it in the bump list in the same change. | Adding a plugin/extension manifest + version-bump registry | Single-file version, or no registry |
| 2026-08-20 | Do not glob-replace em/en dashes with colons or hyphens. Classify the dash (label, aside, contrast, range, cut-off) and rewrite so the sentence still parses. Colon is not a universal substitute. | Any prose/docs edit that removes dashes | User asked to keep decorative dashes |
| 2026-08-21 | A lockfile generated on a newer CPython than CI will fail `pip install` (numpy 2.5 / scipy 1.18 need >=3.12; 3.11 has no wheels). Pin Actions `python-version` to the lock header, and keep a test that the declared minor satisfies Requires-Python for the scientific pins. Failure-path alerts must not import lock-only deps (lazy-import `requests` for GitHub fallback; SMTP is stdlib). | `requirements.lock` (or equivalent) + CI `python-version` | No lockfile, or CI uses the same venv that wrote the lock |
| 2026-08-21 | A vendor daily bar printed during RTH is not a completed session. Trim bars after `expected_last_session` at ingest. Do not fail the whole live job while the last completed session is present (that blocks catch-up). Fail closed only when the completed session is missing or stale. | Live daily forecast ingest from Yahoo-like vendors | Vendor returns only completed sessions, or the job is intraday-native |

Project-only scripts stay in that repo. Promote the **check**, not a one-off path, unless the same surface exists elsewhere.
